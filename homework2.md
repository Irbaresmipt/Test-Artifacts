# First User story + AC (VK video watched before Klips)
###  Как пользователь VK видео, я хочу иметь возможность просматривать ранее просмотренные мною клипы, для того чтобы возвращаться и пересматривать понравившиеся

## Критерии приёмки
- В разделе «Профиль» доступна вкладка «История просмотра».
- Во вкладке «История просмотра» отображаются ранее просмотренные пользователем клипы.
- Для каждого клипа в истории отображается его превью и основная информация о клипе.
- В разделе истории отображаются клипы в порядке от недавно просмотренных к более ранним.
- При нажатии на клип пользователь переходит на страницу просмотра этого клипа.
- В разделе истории отображается кнопка «Показать всё».
- При нажатии на «Показать всё» пользователь переходит к полному списку просмотренных клипов.
- Пользователь может прокручивать список истории свайпом вниз, чтобы просматривать более ранние просмотренные клипы.
- Пользователь может очистить историю просмотра.
- После очистки истории ранее просмотренные клипы больше не отображаются в разделе «История просмотра».
- Если пользователь ещё не просмотрел ни одного клипа, отображается пустое состояние с соответствующим сообщением.

# Second User story + AC (VK video)
###  Как пользователь Vk видео, я хочу иметь возможность скрыть чувствительный и провокационный контент из рекомендаций, чтобы спокойно передавать телефон своим детям

## Критерии приёмки
- В разделе "Главная" добавлена дополнительная кнопка "Cкрыть чувствительный контент"
- При нажатии кнопки весь контент, который предполагается чувствительным (согласуется отдельно), пропадает со страницы Главная
- При перезаходе в приложение режим сохраняется
- При перезапросе рекомендаций режим не сбрасывается
- При повторном нажатии кнопки режим отключается
- Если для пользователя не найдено подходящего контента после применения фильтра, отображается соответствующее пустое состояние, а не чувствительный контент.
